# Backend from the First Principles

A growing collection of structured technical notes and summaries distilled from the **Backend from the First Principles** video series. Each file breaks down one core backend concept from the ground up — how it works, why it exists, and how it compares to alternatives — independent of any specific programming language or framework.

## What This Repo Is

Backend engineering has a huge surface area, and most tutorials jump straight into code, frameworks, or a specific tech stack. This series (and this repo) does the opposite: it focuses on the **underlying mechanisms and concepts** that show up in the majority of real-world backend systems, regardless of what language or framework you use to implement them.

Each note in this repo is a clean, well-organized Markdown summary of a video in the series, built to be read as a standalone reference — not just a rewatch aid.

## What Each File Contains

Every topic file follows a consistent structure so concepts are easy to compare and revisit:

- **What Is [Topic]?** — a high-level definition of the core concept
- **Technical Flow** — the step-by-step lifecycle or process behind it
- **Why Do We Need It?** — the real-world problems it solves
- **Key Comparisons** — how it stacks up against alternatives or common misconceptions
- **Deep Dive** — implementation details, tools, or sub-topics specific to that video
- **Interview Questions & Key Concepts** — categorized questions with talking points, useful for interview prep and self-review

## How to Use This Repo

Each `.md` file is self-contained — read them in any order, though following the series' original sequence will build concepts progressively. Code snippets are only included where a specific syntax or config was explicitly discussed in the source video; the focus throughout is on *concepts*, not implementation.
